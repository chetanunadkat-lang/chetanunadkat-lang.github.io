Privacy policy

Last updated: 16 November 2026

Hermes Jobs is used only by its owner. With the owner's consent it accesses Google Sheets and the Google Drive files it was given access to (scopes: spreadsheets, drive.file). It uses them only to read and update the owner's job-tracker spreadsheet.

Data is processed on the owner's private server. It is not sold, shared with third parties, or used for advertising. Google user data is handled in line with the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at myaccount.google.com/permissions. Questions: open an issue on the GitHub repository.
